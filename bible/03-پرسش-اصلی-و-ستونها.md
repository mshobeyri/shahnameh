# پرسش اصلی و ستون‌های اتصال

معرفی شخصیت فصل بعد فقط اتصال تبلیغاتی است. پیوند واقعی باید علّی باشد.

پرسش‌ها و جواب‌های سریال: [`08-پرسشها-و-مصداقها.md`](08-پرسشها-و-مصداقها.md)

نمادهایی که می‌گویند بازی ادامه دارد: [`09-نمادها.md`](09-نمادها.md)

## سؤال ثابت

وقتی فرمان شاه ناعادلانه است، وفاداری به ایران یعنی اطاعت یا سرپیچی؟

| شخصیت | جواب سریال |
| --- | --- |
| کاوه | سرپیچی |
| ایرج | خشونت را رد می‌کند |
| رستم | بیشتر عمر اطاعت |
| سیاوش | از دروغ سر می‌پیچد |
| کی‌خسرو | تاج را ترک می‌کند |
| اسفندیار | اطاعت |
| رستم در پایان | سرپیچی، دیر |

## دو ستون روایی

### خاندان زال

طرد خودش → تولد رستم → مرگ سهراب → پرورش سیاوش → مرگ سیاوش → تیر گز → خیانت شغاد → مرگ رستم.

### زنجیرهٔ علّی

ظلم ضحاک ← انقلاب فریدون ← تقسیم جهان ← قتل ایرج ← ایران و توران ← وصلت زال و رودابه ← تولد رستم ← خدمت رستم به تاج ← مرگ سهراب ← تربیت سیاوش برای جبران ← مرگ سیاوش ← انتقام کی‌خسرو ← قدرت گشتاسپ ← مرگ اسفندیار ← انزوای رستم ← خیانت شغاد.

درفش و ضحاکِ اسیر حلقهٔ این زنجیره‌اند نه شرحش. شرحشان در دفتر نمادهاست.
