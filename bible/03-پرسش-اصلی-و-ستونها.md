# پرسش اصلی و ستون‌های اتصال

معرفی شخصیت فصل بعد فقط اتصال تبلیغاتی است. پیوند واقعی باید علّی باشد: اتفاق فصل قبل، فاجعهٔ فصل بعد را به وجود بیاورد.

## سؤال ثابت

وقتی فرمان شاه ناعادلانه است، وفاداری به ایران یعنی اطاعت یا سرپیچی؟

| شخصیت | پاسخ | نتیجه |
| --- | --- | --- |
| کاوه | سرپیچی | پیروز می‌شود؛ انقلابش دوباره سلسله می‌شود |
| ایرج | خشونت را رد می‌کند | کشته می‌شود |
| رستم | بیشتر عمر اطاعت می‌کند | سهراب را از دست می‌دهد |
| سیاوش | اطاعت از دروغ را نمی‌پذیرد | تبعید و قتل |
| کی‌خسرو | خودش تاج را ترک می‌کند | چرخه را می‌شکند، اما جانشینانش نه |
| اسفندیار | اطاعت | کشته می‌شود |
| رستم در پایان | سرپیچی، اما دیر | چاه |

## چهار ستون ثابت

### ۱. درفش کاویانی — حافظهٔ مردم

از پیش‌بند ساده شروع می‌شود و در هر فصل تغییر می‌کند.

| فصل | وضعیت درفش |
| --- | --- |
| ۱ | چرم سوخته روی نیزه؛ سپس نخستین گوهر فریدون |
| ۲ | پرچم تاج‌گذاری کی‌قباد؛ چرم زیر دیبا |
| ۳ | رستم زیر آن برای شاه می‌جنگد |
| ۴ | سهراب آن را از دور می‌بیند، بی‌خبر که پدرش زیر آن است |
| ۵ | در ایران می‌ماند؛ سیاوش در توران بدون آن شهر می‌سازد |
| ۶ | کی‌خسرو با آن توران را فتح می‌کند |
| ۷ | گشتاسپ آن را ابزار مشروعیت می‌کند |
| ۸ | در پایتخت است؛ **غیبتش در چاه معنا دارد** |

نباید به‌زور همراه رستم به چاه برود.

خلاصهٔ سیاسی سریال: چیزی که مردم برای مقابله با پادشاه ساختند، کم‌کم به نشان قدرت پادشاهان تبدیل شد.

### ۲. ضحاک — گناهی که هنوز زنده است

فریدون ضحاک را نمی‌کشد؛ او زیر دماوند زنده می‌ماند. این اتصال اصیل شاهنامه است.

گسترش نمایشی، کوتاه و محتاط:

- با قتل ایرج، زنجیر تکان می‌خورد.
- با مرگ سهراب، صدای نفس می‌آید.
- هنگام قتل سیاوش، خون از سنگ عبور می‌کند.
- کی‌خسرو در جام، ضحاک را می‌بیند.
- بعد از مرگ رستم، یکی از میخ‌ها شل می‌شود.

ضحاک نباید شرور نهایی فانتزی شود.

### ۳. خاندان زال — ستون انسانی

زال از تولد تا مرگ رستم پیامد فصل‌های قبل را حمل می‌کند:

طرد خودش → تولد رستم → مرگ سهراب → پرورش سیاوش → مرگ سیاوش → تیر گز → خیانت شغاد → مرگ رستم.

### ۴. زنجیرهٔ علّی — قطع نشود

ظلم ضحاک ← انقلاب فریدون ← تقسیم جهان ← قتل ایرج ← ایران و توران ← وصلت زال و رودابه ← تولد رستم ← خدمت رستم به تاج ← مرگ سهراب ← تربیت سیاوش برای جبران ← مرگ سیاوش ← انتقام کی‌خسرو ← قدرت گشتاسپ ← مرگ اسفندیار ← انزوای رستم ← خیانت شغاد.

این زنجیره سریال را یک داستان نگه می‌دارد. درفش، دماوند و زال کمک می‌کنند مخاطب آن را حس کند، نه فقط بفهمد.
