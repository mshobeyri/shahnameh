# پرسش‌ها

فقط پرسش، و جواب‌هایی که سریال می‌دهد یا نمی‌دهد.

نمادها — درفش، پر سیمرغ، خون سیاوش، ضحاکِ اسیر — اینجا شرح نمی‌شوند. آن‌ها در [`09-نمادها.md`](09-نمادها.md)اند.

پرسش تازه وقتی رسمی است که صورت سؤال و دو ستون جواب ثبت شود.

```
## پرسش: …
جواب‌هایی که سریال می‌دهد:
جواب‌هایی که سریال نمی‌دهد:
```

---

## ۱. وقتی فرمان شاه ناعادلانه است، چه باید کرد؟

### سریال می‌دهد

| کی | جواب | قیمت |
| --- | --- | --- |
| کاوه | طومار را می‌درد | پیروز می‌شود |
| ارمایل و گرمایل | نافرمانی پنهان | چند نفر زنده می‌مانند؛ شاه نمی‌افتد |
| فرانک | کودک را پنهان می‌کند | وارث زنده می‌ماند |
| زال و رودابه | مقابل پدر و شاه می‌ایستند | رستم به دنیا می‌آید |
| رستم بیشتر عمر | اطاعت؛ گاهی پنهان‌کاری نام | سهراب می‌میرد؛ کاووس می‌ماند |
| سیاوش | از دروغ و پیمان‌شکنی سر می‌پیچد | تبعید و قتل |
| پیران | فرمان را آرام دور می‌زند | چند جان؛ خودش تمام می‌شود |
| اسفندیار | اطاعت می‌کند، می‌داند حکم مرگ است | تیر گز |
| رستم در برابر اسفندیار | بند را نمی‌پذیرد | اسفندیار می‌میرد |
| کی‌خسرو | به خودِ تاج «نه» می‌گوید | چرخه برای او می‌شکند؛ برای بعدی نه |
| رستم در چاه | پند بخشش خودش را اجرا نمی‌کند | سقوط دوباره |

### سریال نمی‌دهد

- اینکه همیشه باید نه گفت.
- اینکه همیشه باید اطاعت کرد.
- اینکه کاوه با «نه» گفتن بازی را تمام کرد.
- دیالوگ رستم در چاه: «من مرده‌ام.»

## ۲. برای زنده ماندن باید از کینه گذشت؟

دو کینه را یکی ننویس: شخصی، و خونی که عدالت جمعی شده.

### سریال می‌دهد

| کی | جواب | زنده می‌ماند؟ |
| --- | --- | --- |
| ایرج | از سهم و جنگ می‌گذرد | نه |
| سلم و تور | کینه را انتخاب می‌کنند | جنگ ابدی می‌سازند |
| بیژن | گرگین را می‌بخشد | از چاه بیرون می‌آید |
| رستم به بیژن | بخشش را شرط نجات می‌کند | پندی که خودش در چاه عمل نمی‌کند |
| سیاوش | جنگ را رد می‌کند | کشته می‌شود |
| کی‌خسرو | کین سیاوش را تمام می‌کند، بعد می‌ایستد | تاج را ترک می‌کند |
| شغاد | کینه را با چاه جواب می‌دهد | به درخت دوخته می‌شود |
| رستم در چاه | از کینه نمی‌گذرد | بالا می‌آید و برمی‌گردد |

### سریال نمی‌دهد

- اینکه بخشش همیشه زندگی است. ایرج و سیاوش خلاف این‌اند.
- اینکه انتقام همیشه حق است و باید تا ابد بماند.
- اینکه تقارن دو چاه فقط شعار «ببخش» است. چاه بیژن کینهٔ شخصی است؛ کین سیاوش خون یک بی‌گناه است.

## ۳. خدمت به شاه همان خدمت به ایران است؟

### سریال می‌دهد

| کی | جواب |
| --- | --- |
| رستم | تقریباً تمام عمر: بله. شاه را از مازندران و هاماوران درمی‌آورد |
| سهراب | نه. می‌خواهد با پدر کاووس را کنار بزند |
| سیاوش | نه. دربار را ترک می‌کند و در توران شهر می‌سازد |
| کاووس | بله، چون خودش تاج است. نوشدارو را دیر می‌فرستد |
| گشتاسپ | بله؛ تاج را با دین یکی می‌کند |
| کی‌خسرو در پایان | نه. ایران را از ماندن خودش جدا می‌کند |

### سریال نمی‌دهد

- سخنرانی دربارهٔ درفش. درفش نماد است؛ جواب این پرسش نیست.
- اینکه رستم از قسمت اول این شکاف را فهمیده. تراژدی‌اش دانستنِ دیر است.

---

## ۴. اگر نام و خون پنهان بماند، چه کسی می‌میرد؟

### سریال می‌دهد

| پنهان | جواب سریال |
| --- | --- |
| فرانک / فریدون | پنهان کردن از ستمگر نجات است |
| سام / زال | طرد، شکل دیگری از پنهان کردن است؛ زخم می‌ماند |
| تهمینه / سهراب | پنهان کردن از خویش می‌کشد |
| رستم نامش را از سهراب | می‌کشد |
| فرنگیس / کی‌خسرو | پنهان کردن از ستمگر نجات است؛ بعد شاه باید پدربزرگ را بکشد |
| زال / پیشگویی شغاد | پنهان کردن از خویش چاه می‌سازد |

### سریال نمی‌دهد

- اینکه راز همیشه بد است.
- اینکه اگر همه نامشان را می‌گفتند هیچ‌کس نمی‌مرد. کاووس حتی با دانستن هم نوشدارو را دیر می‌فرستد.

---

## ۵. آیا گریز از تقدیر، تقدیر را می‌سازد؟

### سریال می‌دهد

| کی | فرار | حاصل |
| --- | --- | --- |
| ضحاک | دنبال فریدون می‌گردد | فریدون در کوه ساخته می‌شود |
| سام | زال را رها می‌کند | سیمرغ برمی‌گرداندش |
| افراسیاب | سیاوش را می‌کشد تا خواب نیاید | کی‌خسرو از همان خون می‌آید |
| گشتاسپ | پسر را به مأموریت می‌فرستد تا تاج ندهد | همان مأموریت اسفندیار را می‌کشد |
| زال | اختر شغاد را پنهان می‌کند | شغاد در کابل چاه می‌کند |

### سریال نمی‌دهد

- اینکه تقدیر از آسمان آمد و کسی مقصر نیست.
- اینکه خواب‌ها را باید با صدای راوی تفسیر کرد. ترس شاه کافی است.

---

## ۶. پهلوان را دشمن می‌کشد یا خانه؟

### سریال می‌دهد

افتتاحیه همین جواب است. بعد تکرار می‌شود:

| کشته | قاتل |
| --- | --- |
| مرداس | پسر |
| ایرج | برادران |
| سهراب | پدر |
| سیاوش | دو دربار میزبان |
| فرود | سپاه ایران |
| اسفندیار | شاه خودش فرستاد؛ رستم زد |
| رستم | برادر |

### سریال نمی‌دهد

- اینکه رستم را توران یا دیو کشت.
- اینکه افتتاحیه استثناست. افتتاحیه آخر همین قانون است.

---

## ۷. بعد از پیروزی با تاج چه باید کرد؟

### سریال می‌دهد

| کی | جواب |
| --- | --- |
| فریدون | جهان را قسمت می‌کند | جنگ خانوادگی |
| کاووس | هوس بعدی | رستم باید دوباره نجاتش بدهد |
| کی‌خسرو | تاج را می‌گذارد و می‌رود | تنها خروج آگاهانه |
| گشتاسپ | تاج را نگه می‌دارد | پسر را خرج می‌کند |
| رستم | تاج نمی‌خواهد؛ تاج را زمین نمی‌گذارد | همه تاج‌ها او را مصرف می‌کنند |

### سریال نمی‌دهد

- اینکه فریدون با بستن ضحاک بازی را تمام کرد. بستن، نماد ناتمامی است نه پایان.
- اینکه کی‌خسرو در جام ضحاک را می‌بیند. او از ترس تبدیل‌شدن به شاه بعدی می‌رود؛ مار روی شانه لازم نیست.
- اینکه رستم این سؤال را برای خودش طرح کرده. طرح نکرده.

---

## استفاده

روی بیت‌شیت هر قسمت:

- کدام پرسش؟
- این قسمت کدام جواب را می‌دهد؟
- کدام جواب را هنوز نمی‌دهد؟

نماد جداگانه تیک می‌خورد، در دفتر نمادها.
