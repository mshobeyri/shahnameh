# شاهنامه — بایبل سریال

اتاق نویسندگان زندهٔ اقتباس تلویزیونی شاهنامه. این مخزن فیلمنامهٔ کامل نیست؛ **نسخهٔ رسمی حقیقت** است تا داستان هنگام بازنویسی تناقض پیدا نکند.

هنوز دیالوگ گسترده نوشته نمی‌شود. ترتیب کار:

1. سند مادر
2. دو خط زمانی (جهان / مخاطب)
3. قوس شخصیت‌ها
4. نقشهٔ فصل
5. جدول قسمت
6. بیت‌شیت
7. کارت صحنه
8. نسخهٔ اول فیلمنامه

هر ایدهٔ تازه باید وارد `bible/04-کاشت-و-برداشت.md` شود؛ وگرنه ممکن است فراموش شود یا بی‌نتیجه بماند.
